# FPProxy Checker 1.1.0

Android-приложение для поиска, проверки и подключения MTProto- и SOCKS5-прокси Telegram.

### Что нового
- Новое название **FPProxy Checker** и обновлённая чёткая иконка с Telegram и тёмным щитом.
- Фоновое сканирование с уведомлением и управлением проверкой.
- Несколько источников MTProto, отдельный выключенный по умолчанию SOCKS5.
- Проверка Telegram через TDLib отдельно от TCP, фильтры Telegram OK / TCP OK / Все.
- Настройка числа параллельных проверок.
- Очистка локальной SQLite-базы прокси из настроек.
- Улучшения интерфейса, стабильности сканирования и синхронизации прогресса.

### Установка
Скачайте **FPProxyChecker-v1.1.0.apk** из Assets и откройте его на Android.

**Важное предупреждение о подписи:** APK собран и подписан тестовым ключом GitHub Actions. Если установленная версия подписана другим ключом (например, вашим Android Studio), Android запретит установку поверх неё. Удаление старой версии позволит установить новую, **но удалит локальную базу, избранное и настройки**. Не удаляйте приложение, пока не сохранили необходимые данные. Постоянная релизная подпись пока не настроена.

APK предназначен для ручной установки и тестирования. Поддерживается Android 7.0+ (minSdk 24).
