# FPProxy Checker 1.1.1

Исправление обычной кнопки «Проверка» (↻), которое **сохраняет результаты полной проверки и добавляет новые Telegram OK**.

## Изменения
- Быстрая «Проверка» повторно проверяет ранее доступные по TCP серверы, но временный TCP FAIL, TDLib FAIL или тайм-аут **не стирает ранее подтверждённый Telegram OK**.
- Успешная перепроверка добавляет новые Telegram OK либо обновляет пинг и время успешной проверки.
- Ранее сохранённые MTProto-адреса больше не исчезают из отображаемого списка при быстрой проверке только из-за обновления списков источников.
- «Полная проверка» сохраняет строгий режим: перепроверяет прокси и может обновить текущий результат с Telegram OK на FAIL.
- Новые тесты проверяют сохранение успехов, обновление пинга, сохранение прежних адресов и корректное поведение полной проверки.
- Все возможности 1.1.0, иконка и имя FPProxy Checker сохранены.

**Важно:** Telegram OK, сохранённый после неудачной быстрой проверки, означает *ранее подтверждённую работоспособность*, а не гарантию доступности сейчас. В подробностях прокси хранится время последнего успешного подтверждения.

## Установка
Скачайте `FPProxyChecker-v1.1.1.apk` ниже и откройте на Android.

**Подпись:** APK выпускается средствами GitHub Actions с временным debug-ключом. Android может отказать в обновлении поверх 1.1.0 или локальной сборки из-за другой подписи. Удаление предыдущей установки приводит к **потере локальной базы прокси, избранного и настроек**. Перед удалением сохраните важные данные; если их сохранение невозможно, не удаляйте приложение. Для будущего бесшовного обновления нужен постоянный ключ подписи.
