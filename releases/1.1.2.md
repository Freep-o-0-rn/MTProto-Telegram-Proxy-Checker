# FPProxy Checker 1.1.2

Версия 1.1.2 уточняет отображение MTProto-прокси, у которых Telegram-проверка через TDLib успешна, хотя предварительная TCP-проверка не прошла.

## Что изменилось
- **TCP OK + Telegram OK** — обычный рабочий прокси.
- **TCP FAIL + Telegram OK** — остаётся в разделе **Telegram OK**, но помечается жёлтой строкой **«⚠ Нестабильно · TCP FAIL»**.
- В карточке такого прокси сохраняется кнопка подключения к Telegram; в подробностях показано пояснение расхождения результатов.
- В списке Telegram OK обычные TCP OK + Telegram OK показываются выше нестабильных.
- Обычная кнопка **«Проверка»** (↻) теперь перепроверяет также нестабильные Telegram OK, даже если их TCP-подключение снова не проходит; успешная TDLib-проверка обновляет результат.
- При временной ошибке быстрой проверки ранее подтверждённый Telegram OK сохраняется согласно логике 1.1.1.
- Добавлены регрессионные тесты классификации, сортировки, повторной проверки и перехода из нестабильного состояния в обычный Telegram OK.
- Формат SQLite не изменён, дополнительная миграция не требуется.

**Важно:** «Нестабильно» означает расхождение между TCP Socket.connect и успешным TDLib TestProxy, а не доказанную невозможность подключения: Telegram может успешно работать с таким прокси. Признак вычисляется из сохранённых результатов TCP и TDLib.

## Установка
Скачайте `FPProxyChecker-v1.1.2.apk` из вложений этого релиза.

**Внимание к подписи и данным:** APK собран GitHub Actions и подписан debug-ключом, который может отличаться от ключа уже установленной сборки (включая 1.1.0/1.1.1). В таком случае Android заблокирует установку как обновление. Удаление прежней версии **удаляет локальную SQLite-базу прокси, избранное и настройки**. Не удаляйте приложение ради обновления, если эти данные нужно сохранить. Для последующих бесшовных обновлений потребуется постоянный ключ подписи.
