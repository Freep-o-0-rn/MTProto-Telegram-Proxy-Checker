# TelegramProxyChecker

Android-приложение для поиска и проверки MTProto-прокси для Telegram.

Приложение загружает список MTProto-прокси, проверяет доступность сервера по TCP, затем выполняет реальную проверку через Telegram-клиентский слой с использованием TDLib. Это позволяет отличать просто открытый порт от прокси, который действительно может работать с Telegram.

[⬇️ Скачать последнюю версию APK](https://github.com/Freep-o-0-rn/TelegramProxyChecker/releases)

## Возможности

- загрузка списка MTProto-прокси из открытого источника;
- TCP-проверка `server:port`;
- реальная Telegram-проверка через TDLib `TestProxy`;
- отображение статусов `TCP OK / FAIL` и `Telegram OK / FAIL`;
- сортировка рабочих прокси выше нерабочих;
- кэширование результатов проверки;
- повторное использование свежих результатов до 30 минут;
- избранные прокси;
- точечная повторная проверка одного прокси;
- фильтр рабочих прокси;
- фильтр избранных прокси;
- переход в Telegram для подключения выбранного прокси.

## Как работает проверка

Приложение выполняет две проверки:

1. **TCP-проверка**  
   Проверяется, открывается ли соединение с `server:port`.

2. **Telegram-проверка**  
   Проверяется MTProto-прокси через TDLib. Такой тест показывает, может ли прокси реально использоваться Telegram, а не просто имеет открытый порт.

Возможные результаты:

```text
TCP: OK
Telegram: OK
```

Прокси доступен и прошёл Telegram-проверку.

```text
TCP: OK
Telegram: FAIL
```

Порт открыт, но как Telegram-прокси сервер не работает.

```text
TCP: FAIL
Telegram: FAIL
```

Сервер недоступен.

## Кэширование

Кэш нужен для быстрого запуска приложения и уменьшения количества повторных проверок.

Логика работы:

1. При запуске приложение сразу показывает сохранённый список из кэша.
2. Прокси, проверенные менее 30 минут назад, повторно не проверяются.
3. Сначала перепроверяются ранее рабочие `Telegram OK` прокси.
4. Затем проверяются новые прокси.
5. После этого ограниченно перепроверяются старые `Telegram FAIL` прокси.
6. Избранные прокси сохраняются между запусками.

## Избранное

Прокси можно отметить звездой. Избранные прокси:

- сохраняются в кэше;
- отображаются выше обычных прокси;
- могут быть отфильтрованы отдельной кнопкой.

## Точечная проверка

У каждого прокси есть кнопка повторной проверки. Она запускает проверку только выбранного сервера, не перепроверяя весь список.

Во время проверки кнопка показывает вращающиеся стрелки.

## Сборка проекта

Открыть проект в Android Studio и выполнить сборку:

```powershell
.\gradlew clean :app:assembleDebug
```

Для запуска на телефоне нужен включённый режим разработчика и отладка по USB.

## Важно

Проект не является официальным продуктом Telegram. Приложение не владеет прокси-серверами и не гарантирует их стабильность. MTProto-прокси могут быстро переставать работать, поэтому результаты проверки всегда имеют ограниченный срок актуальности.

## Лицензия

Проект распространяется под лицензией Apache-2.0.
